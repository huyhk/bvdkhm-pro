# Tóm tắt đề án nâng cấp Cổng thông tin điện tử

Bản HTML 8 trang dành cho lãnh đạo đọc trước khi xem bộ đề án đầy đủ.

## Xem trên PC
Chạy `preview.bat`, sau đó mở `http://localhost:8080`.

## Điều khiển
- `←` / `→`: chuyển trang
- `Home` / `End`: trang đầu / cuối
- `F`: toàn màn hình
